# SMART OFFICE: المزامنة بين الأجهزة + تثبيت كتطبيق

عندك 3 خطوات، وتتعمل مرة واحدة فقط.

## 1) السحابة (عشان البيانات تفتح من أي جهاز): Firebase مجاني

1. ادخل https://console.firebase.google.com بحساب جوجل، واضغط **Add project** وسمّه أي اسم.
2. من القائمة الجانبية: **Build ← Realtime Database ← Create Database**. اختر أي منطقة، وابدأ بـ **Locked mode**.
3. افتح تبويب **Rules** والصق هذا الكود بالكامل، ثم **Publish**:
   ```
   { "rules": { "offices": { "$id": { ".read": true, ".write": true } } } }
   ```
4. انسخ **رابط القاعدة** من أعلى تبويب Data. يبدو هكذا: `https://اسم-مشروعك-default-rtdb.firebaseio.com`

> الأمان: البيانات تتشفر على جهازك بـ AES قبل الرفع، ومسار التخزين مشتق من «كود المكتب» السري. بدون الكود لا أحد يقدر يقرأها. اختر كوداً طويلاً (زر «توليد» يعمل ذلك).

## 2) استضافة التطبيق (للكمبيوتر والتثبيت من المتصفح)

1. افتح https://app.netlify.com/drop وأسقط عليه **هذا المجلد كله**.
2. تحصل على رابط https. افتحه في Chrome أو Edge على الكمبيوتر، ثم اضغط أيقونة **التثبيت** في شريط العنوان (أو الإعدادات ← «تثبيت التطبيق»). يشتغل كبرنامج مستقل.
3. على الهاتف: افتح نفس الرابط ← قائمة المتصفح ← **تثبيت التطبيق / إضافة للشاشة الرئيسية**.

## 3) تفعيل المزامنة

1. على الجهاز الأول: سجّل دخول كمدير ← **الإعدادات ← المزامنة السحابية**. الصق رابط Firebase، اضغط **توليد** للكود، ثم **تفعيل المزامنة**.
2. اضغط **نسخ كود ربط جهاز جديد**.
3. على أي جهاز آخر: في شاشة الدخول اضغط **ربط هذا الجهاز بمكتب موجود**، الصق الكود، وسجّل دخولك بكلمة مرورك.

بعدها أي تعديل يظهر على باقي الأجهزة خلال ثوانٍ (وتتم المزامنة تلقائياً كل 45 ثانية). لو انقطع الإنترنت تكمل الشغل وتترفع التعديلات عند عودته.

## 4) ملف APK للأندرويد (يُبنى تلقائياً مجاناً)

1. أنشئ حساباً على https://github.com وأنشئ مستودعاً جديداً (Repository).
2. ارفع محتويات هذا المجلد كلها إليه، **بما فيها المجلد المخفي `.github`**.
3. افتح تبويب **Actions ← Build APK ← Run workflow**. بعد حوالي 5 إلى 8 دقائق افتح التشغيل المكتمل ونزّل **smart-office-apk** من قسم Artifacts، واستخرج `app-debug.apk`.
4. انقله للهاتف وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

## ملاحظات

- **المرفقات (صور الهويات وPDF)** تُحفظ على الجهاز الذي رُفعت منه ولا تُزامَن بين الأجهزة. باقي البيانات (عملاء، ملفات، تحصيلات، مصروفات، مهام، موظفون) كلها تتزامن.
- لو عدّل جهازان نفس السجل في نفس اللحظة، يُحفظ الأحدث. تعديل جهازين في سجلين مختلفين لا يتعارض.
- أرقام الملفات (F-2026-0005) تُولَّد على كل جهاز، فلو أضاف جهازان ملفاً في نفس الدقيقة قد يتكرر الرقم. نادر.
- في تطبيق APK قد لا يعمل زر **تصدير Excel / النسخة الاحتياطية كملف**. استخدم زر «نسخ» بدلاً منه. الأفضل التصدير من الكمبيوتر.
- لا تحذف مشروع Firebase ولا تفقد «كود المكتب». احتفظ به أو بكود الربط في مكان آمن.
